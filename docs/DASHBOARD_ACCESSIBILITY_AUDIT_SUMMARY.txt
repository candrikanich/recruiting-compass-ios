================================================================================
WCAG CRITERIA MOST FREQUENTLY VIOLATED
================================================================================

1. 4.1.2 Name, Role, Value (Affected: 18 issues)
   - Missing accessibility labels on buttons
   - Missing accessibility hints on controls
   - Unclear button purpose/action

2. 1.1.1 Non-text Content (Affected: 8 issues)
   - Charts without text alternatives
   - Color-only indicators without text
   - Icons without proper hiding

3. 2.5.5 Target Size (Affected: 6 issues)
   - Touch targets below 44x44 minimum
   - Motor disability users cannot reliably interact

4. 1.4.4 Resize Text (Affected: 5 issues)
   - Hard-coded font sizes not scaling with Dynamic Type
   - Truncation at accessibility sizes

5. 1.3.1 Info and Relationships (Affected: 7 issues)
   - Content grouping issues
   - Missing semantic structure

6. 4.1.3 Status Messages (Affected: 3 issues)
   - Dynamic content not announced (loading, errors)
   - Missing live region traits
