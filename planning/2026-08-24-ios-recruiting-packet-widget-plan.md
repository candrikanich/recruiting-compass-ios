# iOS Recruiting Packet Widget — Implementation Plan

**Date:** 2026-08-24
**Goal:** Port web's dashboard "Recruiting Packet" widget to iOS for parity.
**Direction:** web → iOS (web is source of truth; no web change needed).
**Output decision (Chris):** Native SwiftUI + PDF (not HTML reuse).

---

## Web behavior (source of truth)

`components/Dashboard/RecruitingPacketWidget.vue` + `composables/useRecruitingPacket.ts` +
`utils/recruitingPacketExport.ts`.

Widget = small launcher card, NOT role-gated, athlete-scoped. Two actions:
- **Generate Packet** → aggregates athlete profile + schools-by-tier + activity summary → document → print/save PDF.
- **Share with a coach** → links to `/coaches`.

Aggregated packet content:
- **Cover:** name, position line, `{School} • Class of {gradYear}`, `Generated on {date}`.
- **Athlete Profile:** Height / Weight / Bats-Throws / Position stat cards; Contact Info (email fallback
  "Not provided", phone only if `allow_share_phone`, fallback "Available upon request"); Academic Info
  (GPA 2-dec / SAT / ACT, core courses); Video Links; Activity Summary (total schools, total interactions,
  recent contact or N/A); Interaction Breakdown (Emails/Calls/Camps/Visits/Other).
- **Schools of Interest:** Priority A/B/C tables (School Name, Location, Division, Conference, Status).
  Empty tiers omitted.
- **Footer:** "This recruiting packet was generated by The Recruiting Compass." + timestamp.

Tier grouping: A = `offer_received`|`committed`; B = `visiting`; C = else.
Activity breakdown: emails=`email`; calls=`phone_call`; camps=`camp`|`showcase`;
visits=`in_person_visit`|`unofficial_visit`|`official_visit`|`virtual_meeting`; other=else.
Bats/Throws = `R/R`, degrade to `R/—`. Height = `feet'inches"`. Position = coach-facing short form.

## iOS approach

Model after existing PDF export: `Features/Performance/Utilities/PerformancePDFGenerator.swift`
(`@MainActor`, `UIGraphicsPDFRenderer`, 612×792pt US Letter, 50pt margin) + share via
`Features/Performance/Components/ShareSheetView.swift` (`Data`→temp file→`ShareLink`).

Widget = launcher card (matches web). Lazy on-demand: schools + interactions come in as inputs from
`DashboardViewModel` (already fetched, no double-fetch); the widget's own VM fetches ONLY the extra bits
(`PlayerDetails` via `PreferenceManaging`, `User` via authManager, video links via `VideoLinksManaging`)
when **Generate** is tapped — nothing loads on dashboard render. Precedent: `RecentActivityWidget`
self-loads.

### New files
1. `Features/Dashboard/Models/RecruitingPacketData.swift` — aggregated struct + pure fns
   `groupSchoolsByTier(_:)` and `activityBreakdown(_:)` (mirror web mapping exactly).
2. `Features/Dashboard/ViewModels/RecruitingPacketViewModel.swift` — `@MainActor @Observable`,
   `nonisolated deinit {}` (known-issue guard). Deps injected via protocols (`PreferenceManaging`,
   `VideoLinksManaging`, `AuthManaging`). `func generate(schools:interactions:) async -> Data`.
3. `Features/Dashboard/Utilities/RecruitingPacketPDFGenerator.swift` — `@MainActor`,
   `UIGraphicsPDFRenderer`, draws cover + profile + schools tables + footer per spec above.
4. `Features/Dashboard/Components/RecruitingPacketWidget.swift` — card: title "Recruiting Packet",
   "Generate Packet"/"Generating…" button (spinner + disabled while loading), "Share with a coach"
   secondary action, error banner. On generated `Data` → `.sheet { ShareSheetView(data:filename:) }`.
   Filename `{Name}_RecruitingPacket.pdf`.

### Edited files
5. `Core/Utilities/HeightFormatter.swift` (new small util) — extract `formatHeight(inches:)` currently
   private in `PublicProfile/Components/PublicProfileSections.swift:333`; refactor that call site to use
   it (no duplication).
6. `Features/Preferences/Models/WidgetVisibility.swift` — add `recruitingPacket: Bool` in all 5 spots
   (property, `default`, `CodingKeys`, memberwise `init`, `init(from:)` decode-if-present ?? true).
7. `Features/Dashboard/Views/DashboardView.swift` — mount `RecruitingPacketWidget` **directly after
   `DashboardStatsCardsSection`** (top of scroll, above Action Items), gated by
   `if visibility.recruitingPacket` (always shown when on — it's a launcher, no empty-data gate). Pass
   schools/interactions/targetUserId + a tab-switch callback (reuse existing stat-card tab-switch
   mechanism) for "Share with a coach" → Coaches tab nav.
9. `Features/.../DashboardCustomizationView.swift` + `DashboardCustomizationViewModel.swift` — add the
   toggle row (parity with other widget toggles).

### Tests (model after `PerformancePDFGeneratorTests`)
- `RecruitingPacketPDFGeneratorTests` — `@MainActor`, asserts non-empty PDF `Data`, `%PDF` header.
- `RecruitingPacketDataTests` — tier grouping + activity breakdown pure-fn coverage (mirror web spec
  cases incl. deprecated status decode + degrade paths).
- `WidgetVisibilityTests` — `recruitingPacket` defaults true when key absent (decode-if-present).

## Parity notes
- iOS-only addition (web already ships it) — parity direction one-way.
- "Share with a coach": web links to `/coaches` list; iOS switches to Coaches tab (platform-idiomatic
  nav, identical intent). Packet PDF itself shares via system share sheet.
- Not role-gated (both player + parent); parent-view uses resolved `targetUserId` (same as other widgets).

## Decisions (resolved 2026-08-24)
- **Placement:** top of scroll — directly after stat cards, above Action Items.
- **Cover photo:** include `profile_photo_url` — async-fetch, draw into PDF cover, graceful fallback
  (placeholder / omit) on missing or failed load. Photo fetch happens in the widget VM's generate flow.
